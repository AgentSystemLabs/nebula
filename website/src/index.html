Stop reading screens. Read a colour.

You start three Claude sessions in three terminal tabs. Five minutes later you don't know which one is waiting on a permission prompt, which one finished, and which one is still thinking, so you tab through them all and read.

Orbit replaces the reading with a grid and a colour. Every session is a card with a status dot. Cards sit in a band per git checkout, under project tabs that add up their sessions' dots. A red count on a tab tells you exactly where to look.

One Rust binary and a unix socket. No Electron, no browser, no server.

  • WorkingClaude is in the middle of a turn.
  • Needs youA permission prompt or a question. Orbit plays a sound and sends a notification.
  • Done, unreadThe turn finished and you haven't looked yet.
  • DoneFinished, and you've seen it.

Everything a day of parallel agents needs.

Many sessions, many worktrees, one screen, and keys you can remember. The keycap beside each one is the key that opens it.

Enter

One screen, every session

Project tabs, a band per worktree, a card per session, and the live terminal of the card under the cursor beside them.

;

Dots instead of screens

Every card and every tab counts its dots. Red sends a desktop notification, and ; jumps to the next session that needs you.

q

Sessions outlive the window

A daemon owns them. Quit Orbit, close the laptop, come back tomorrow: nothing stopped, and the output is replayed when you return.

p

A task box, not a picker

Press p, type the task, press Enter. Ctrl+N runs it in a fresh git worktree so parallel agents never edit the same files.

Ctrl+S

Several skills per prompt

Tick exactly the skills a prompt should use: personal, project or plugin. Save a set as a workflow and commit it for your team.

s

Limits and context at a glance

The footer shows your plan's 5-hour and weekly use, and each card shows how full its context is: amber from 80%, red from 95%.

k

Code graph, built in

A graphify knowledge graph of every checkout, kept fresh without an LLM, so Claude queries it before grepping file by file.

g

Review without leaving

A diff with reviewed marks, a full-screen git graph, a file finder, search in files and a file tree, all scoped to the card's checkout.

v

GitHub in place

Every band shows its branch's pull request. Read, diff and comment on PRs, or start a session from an issue. Needs gh.

F10

Claude drives Orbit back

Say "do this in a worktree" or "start a session that writes the tests", and the session runs the right orbit command itself.

h

Keys you can remember

Arrows to move, letters that mean something, nothing that needs ⌥ or a dead key on an AZERTY Mac. Every key can be rebound.

doctor

One-time setup check

orbit doctor shows what your machine has and what each missing piece unlocks. --fix installs the integrated tools once.

Install

Pick your system. The same command installs and updates. Prebuilt binaries cover Apple Silicon and Intel Macs, and x86_64 and ARM64 Linux.

  1. Install what Orbit needs

    Git, uv and npm through Homebrew, then Claude Code itself. gh is optional, for pull requests and issues.

    $ brew install git uv node gh
    $ curl -fsSL https://claude.ai/install.sh | bash

    Other ways to install Claude Code are in the official setup guide. Run claude once to sign in.

  2. Install Orbit

    With Homebrew recommended

    $ brew tap amenadem/orbit https://github.com/AmenAdem/Orbit
$ brew install amenadem/orbit/orbit

    Type the full name amenadem/orbit/orbit. A plain brew install orbit installs an unrelated Mac app.

    Or with the install script, into ~/.local/bin:

    $ curl -fsSL https://raw.githubusercontent.com/AmenAdem/Orbit/main/install.sh | sh

  3. Check your setup and start

    doctor --fix installs graphify and agent-browser once.

    $ orbit doctor --fix
$ cd ~/code/my-app && orbit

  1. Install what Orbit needs

    Git, curl and npm from your package manager, uv from Astral, then Claude Code.

    # Debian, Ubuntu
$ sudo apt update && sudo apt install -y git curl nodejs npm
# Fedora
$ sudo dnf install -y git curl nodejs npm
# Arch
$ sudo pacman -S git curl nodejs npm
    $ curl -LsSf https://astral.sh/uv/install.sh | sh
$ curl -fsSL https://claude.ai/install.sh | bash

    Optional: the GitHub CLI (gh) for pull requests and issues.

  2. Install Orbit

    The script installs a static binary (x86_64 or aarch64) into ~/.local/bin. Set ORBIT_INSTALL_DIR to put it somewhere else.

    $ curl -fsSL https://raw.githubusercontent.com/AmenAdem/Orbit/main/install.sh | sh

    If ~/.local/bin isn't on your PATH yet, the installer says so. Add it to ~/.bashrc or ~/.zshrc:

    $ export PATH="$HOME/.local/bin:$PATH"

    Homebrew on Linux works too, with the same two commands as on macOS.

  3. Check your setup and start

    $ orbit doctor --fix
$ cd ~/code/my-app && orbit

Orbit's daemon needs unix sockets, so on Windows it runs inside WSL2, as Linux. Native Windows and WSL1 are not supported.

  1. Turn on WSL2

    Run this in PowerShell as Administrator, then restart when it asks. It installs WSL2 with Ubuntu.

    PS> wsl --install

    Already have WSL? Check it is version 2 with wsl -l -v, and convert with wsl --set-version Ubuntu 2.

  2. Inside Ubuntu, install what Orbit needs

    $ sudo apt update && sudo apt install -y git curl nodejs npm
$ curl -LsSf https://astral.sh/uv/install.sh | sh
$ curl -fsSL https://claude.ai/install.sh | bash

  3. Install Orbit and start

    $ curl -fsSL https://raw.githubusercontent.com/AmenAdem/Orbit/main/install.sh | sh
$ orbit doctor --fix
$ cd ~/code/my-app && orbit

    Keep your repositories in the Linux filesystem (~/code), not under /mnt/c: git and file watching are much faster there. Windows Terminal is a good home for Orbit.

  1. Install Rust

    For any platform without a prebuilt binary, or to hack on Orbit. You also need git, make, and the tools listed below.

    $ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

  2. Build and install

    $ git clone https://github.com/AmenAdem/Orbit.git && cd Orbit
$ make install PREFIX=$HOME/.local/bin
$ orbit reload   # move a running daemon onto the new build

    Or straight from git with cargo:

    $ cargo install --git https://github.com/AmenAdem/Orbit orbit --locked

  3. Working on Orbit itself?

    make dev runs an isolated copy with its own daemon and data. See Contributing.

Updating

When a release is out, Orbit's footer shows ⇡ vX.Y.Z. One command updates and moves the running daemon onto the new binary, without stopping a session. After a plain brew upgrade, run orbit reload to do that last step yourself.

$ orbit upgrade

Uninstalling

Stop the daemon, then remove the binary the way you installed it. Settings and the session database live where orbit config path points; delete that folder too for a clean slate.

$ orbit kill
$ rm ~/.local/bin/orbit                # script install
$ brew uninstall amenadem/orbit/orbit  # Homebrew

Your first session.

Open a terminal inside a repository and run orbit. Then:

  1. On the splash screen press Enter to open the repository you're in. Anywhere else, o browses for a folder.
  2. Press p, type what you want done, press Enter. A card appears with a yellow dot.
  3. Do something else. When the dot turns blue or red, press ; to land on it and Enter to step in. Ctrl+Q steps back out.
  4. q quits, and the sessions keep running. Run orbit again to pick them up.

Sessions name themselves from your first prompt (Fix Login Redirect, not agent-3). Press h any time for every key.
